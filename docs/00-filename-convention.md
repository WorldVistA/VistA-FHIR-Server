# Docs Directory Filename Convention

## Naming Convention

- **Prefix**: `NN-category-` (e.g., `01-spec-`, `02-arch-`) for sort order on GitHub
- **Body**: Lowercase, hyphen-separated words
- **Extension**: `.md` (or `.m` for MUMPS)

## Goals

1. **Cross-platform**: No spaces; hyphens; lowercase (Linux/Windows safe)
2. **Content clarity**: Filenames reflect document purpose
3. **Sort order**: Numeric prefixes group related docs
